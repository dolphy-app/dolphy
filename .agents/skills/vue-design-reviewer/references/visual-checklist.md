# Чек-лист визуальной проверки

Адаптировано из `web-design-reviewer/references/visual-checklist.md` (github/awesome-copilot). Идти по разделам, отмечая только то, что проверено измерением или скриншотом. Пороги — WCAG 2.x AA.

## 1. Вёрстка

- Нет горизонтального скролла: `documentElement.scrollWidth <= clientWidth` на каждой проверяемой ширине.
- Контент не вылезает из родителя; изображения, таблицы и блоки кода укладываются в контейнер или скроллятся осознанно.
- Элементы не перекрывают друг друга (кроме оверлеев: меню, диалог, снэкбар).
- Выравнивание сеток и flex-рядов, иконка и текст на одной вертикали, подписи полей рядом с полями.
- Layout-компоненты Vuetify (`v-app-bar`, `v-navigation-drawer`) не перекрывают контент; порядок при необходимости задан `order`.
- На больших ширинах (1920) контент не растягивается до нечитаемых строк: задан максимум ширины.

## 2. Типографика

- Размер основного текста ≥ 16px там, где это не плотный интерфейс; иерархия заголовков читается.
- Межстрочный интервал 1.5–1.8 для абзацев; длина строки 40–80 знаков.
- Длинные слова, URL, идентификаторы переносятся или обрезаются с `…`, а не рвут вёрстку.
- Русские подписи длиннее английских: кнопки, табы, заголовки колонок не обрезаются и не переносятся некрасиво.
- Шрифты загрузились (Roboto подключён явно), спецсимволы и эмодзи отображаются.
- Vuetify 4: варианты типографики названы по MD3 (`display-*`, `headline-*`, `body-large`, `label-large`); старые имена (`h1`–`h6`, `subtitle-1`, `body-1`, `caption`, `button`) не срабатывают.

## 3. Цвет и контраст

- Обычный текст ≥ 4.5:1; крупный (от 24px или от 18.66px жирный) ≥ 3:1.
- Границы полей, иконки и индикаторы состояния ≥ 3:1 к фону.
- Focus-индикатор заметен на фоне и не перекрыт `overflow: hidden` родителя.
- Информация не передаётся только цветом (ошибка — ещё иконка/текст).
- Оба режима темы: светлая и тёмная (в Vuetify 4 по умолчанию `system`). Жёстко заданные цвета (`#fff`, `#000`, серые) ломают одну из тем.
- Цвета из токенов темы, не из произвольных hex; единый цвет ошибки, успеха, ссылки.
- Проверять `tab.a11y()`: правила axe про контраст и метки.

## 4. Адаптивность

- 375 / 768 / 1280 / 1920, для `apps/desktop` — допустимые размеры окна Electron.
- Нет обрезанного или исчезнувшего контента на промежуточных ширинах, нет дублей.
- Сетка Vuetify 4 (`v-row`/`v-col` на CSS `gap`): нет отрицательных полей; `dense` не работает, вместо него `density="compact"`; `align`/`justify` у `v-row` и `order`/`align-self` у `v-col` заменены утилитарными классами.
- Цели нажатия ≥ 44×44px на сенсорных ширинах; на десктопе плотность допустима, но кликабельная зона не меньше видимой иконки.

## 5. Состояния интерактивных элементов

- Кнопки: обычное, hover, focus, active, disabled (отличимо от обычного), loading.
- Ссылки: отличимы от текста, hover и focus.
- Поля: граница различима, focus, ошибка с текстом, обязательность, placeholder не заменяет метку, disabled/readonly.
- Выпадающие списки, меню, диалоги открываются, закрываются с клавиатуры (Esc), не обрезаются краем окна.
- Пустое, загрузка, ошибка, длинный список — для каждого списка и каждой формы.

## 6. Изображения, иконки, медиа

- Пропорции сохранены, размер соответствует контейнеру, поведение при ошибке загрузки.
- Иконки не пустые: подключён `@mdi/font` (или SVG-набор); иконки без текста имеют `aria-label`/`title`.

## 7. Доступность

- Все интерактивные элементы достижимы Tab, порядок фокуса логичен, ловушка фокуса есть только у модалок.
- У полей есть метки, у иконок-кнопок — имя, иерархия заголовков не перескакивает.
- `prefers-reduced-motion`: анимации не обязательны для понимания [если поддерживается компонентом].
- axe: нарушений уровня serious/critical нет; moderate разобрать, отметить осознанные.

## 8. Динамика

- Нет скачков раскладки при загрузке данных, шрифтов, изображений.
- Переходы плавные, без залипания при прокрутке.
- Консоль без ошибок и предупреждений Vue/Vuetify.

## Приоритеты

|Приоритет|Что|
|---|---|
|P0|функциональность сломана: перекрытие, пропавший контент, story падает|
|P1|нечитаемый текст, контраст ниже порога, нет focus, недоступный элемент, горизонтальный скролл|
|P2|выравнивание, неровные отступы, обрезка текста|
|P3|мелкие расхождения в положении и оттенках|
