# Агрегатные функции

Агрегат сворачивает набор строк в одно значение.

- `count(*)` считает строки, `count(x)` — строки, где `x` **не** `NULL`, `count(DISTINCT x)` — различные известные значения.
- `sum`, `avg`, `min`, `max` **пропускают** `NULL`. Поэтому `avg(x)` ≠ `sum(x) / count(*)`; чтобы считать неизвестное нулём, пишут `avg(coalesce(x, 0))`.
- Если подходящих строк нет: `count` = 0, а `sum`, `avg`, `min`, `max` = `NULL` (`total(x)` вернёт 0.0).
- Агрегат нельзя использовать в `WHERE`: сначала фильтруются строки, потом считаются агрегаты.
