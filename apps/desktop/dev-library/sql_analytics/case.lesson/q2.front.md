**Найдите ошибку.** Запрос должен вернуть для каждого отдела (`dept_id`, включая неизвестный) число сотрудников с бонусом `with_bonus` и без него `without_bonus`. Оба столбца показывают общую численность отдела:

```sql
SELECT dept_id,
  count(CASE WHEN bonus IS NOT NULL THEN 1 ELSE 0 END) AS with_bonus,
  count(CASE WHEN bonus IS NULL THEN 1 ELSE 0 END) AS without_bonus
FROM emp
GROUP BY dept_id;
```
