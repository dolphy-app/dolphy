# Коррелированные подзапросы и EXISTS

Коррелированный подзапрос ссылается на столбцы внешнего запроса и логически выполняется заново **для каждой строки** внешнего.

```sql
SELECT name FROM emp e
WHERE salary > (SELECT avg(salary) FROM emp WHERE dept_id = e.dept_id);
```

- Внешней таблице нужен псевдоним, а корреляция — условие вида `inner.key = outer.key`. Без него подзапрос становится обычным и возвращает одно и то же для всех строк.
- `EXISTS (подзапрос)` — есть ли хотя бы одна строка; список столбцов внутри неважен (`SELECT 1`). `NOT EXISTS` — анти-соединение, которое, в отличие от `NOT IN`, не ломается из-за `NULL`.
- `EXISTS` не размножает строки, как `JOIN`: клиент с тремя заказами выводится один раз.
- Если ключ внешней строки `NULL`, условие `inner.key = NULL` неизвестно, и подзапрос ничего не находит.
