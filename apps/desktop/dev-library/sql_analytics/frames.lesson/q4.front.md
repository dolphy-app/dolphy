**Найдите ошибку.** Запрос должен вернуть для каждого сотрудника с известным отделом имя `newest` — самого недавно принятого сотрудника его отдела. Сейчас в `newest` каждый получает своё собственное имя:

```sql
SELECT name, dept_id,
  last_value(name) OVER (PARTITION BY dept_id ORDER BY hired) AS newest
FROM emp
WHERE dept_id IS NOT NULL;
```

Исправьте запрос.
