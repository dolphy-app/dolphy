# GROUP BY и HAVING

`GROUP BY` делит строки на группы по значениям ключей, агрегаты считаются в каждой группе отдельно.

```sql
SELECT dept_id, count(*) AS n FROM emp GROUP BY dept_id;
```

- `NULL` в ключе — **отдельная группа**, а не «исчезнувшие» строки.
- `WHERE` фильтрует строки **до** группировки, `HAVING` — группы **после** подсчёта агрегатов. Условие на агрегат (`count(*) > 2`) возможно только в `HAVING`.
- В списке `SELECT` допустимы ключи группировки и агрегаты. SQLite молча принимает и «голый» столбец, но берёт его значение из произвольной строки группы — так писать нельзя.
- Ключей может быть несколько: `GROUP BY dept_id, title`.
