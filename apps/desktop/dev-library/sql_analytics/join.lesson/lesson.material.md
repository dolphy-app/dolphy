# JOIN: внутреннее соединение

`JOIN ... ON` склеивает строки двух таблиц по условию. Внутреннее соединение оставляет только пары, для которых условие истинно.

```sql
SELECT e.name, d.name AS dept
FROM emp e
JOIN dept d ON d.id = e.dept_id;
```

- Таблицам дают псевдонимы (`emp e`), а столбцы пишут с квалификатором (`e.name`): в обеих таблицах есть `name`.
- Строка с `NULL` в ключе соединения ни с чем не сопоставляется и выпадает из внутреннего соединения.
- Без `ON` получается декартово произведение: каждая строка с каждой.
- Соединять можно цепочкой: `a JOIN b ON ... JOIN c ON ...`.
- Если связь «один ко многим», строка «одной» стороны повторяется по числу связанных строк; ненужные повторы убирает `DISTINCT`.
