# JOIN и агрегаты

Отчёт «по каждому X» обычно строится так: соединить таблицы, затем сгруппировать.

- Чтобы в отчёте остались «пустые» X (отдел без сотрудников), соединяйте `LEFT JOIN` от таблицы X и считайте `count(правая.id)`: `count(*)` посчитает и строку-заглушку с `NULL`, то есть даст 1 вместо 0.
- **Размножение строк.** При цепочке «клиент → заказы → позиции» строка заказа повторяется по числу позиций. Число заказов поэтому считают как `count(DISTINCT o.id)`, а сумму по позициям — `sum(qty * price)`.
- `sum` по пустой группе даёт `NULL`; «ноль вместо неизвестного» — `coalesce(sum(x), 0)`.
- Условия на агрегат после соединения — `HAVING`, условия на исходные строки — `WHERE`.
