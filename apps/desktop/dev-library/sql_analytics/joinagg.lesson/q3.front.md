**Найдите ошибку.** Запрос должен вернуть для каждого клиента число его неотменённых заказов `orders_n` и выручку `revenue`. Число заказов получается завышенным:

```sql
SELECT c.name, count(o.id) AS orders_n, sum(oi.qty * p.price) AS revenue
FROM customer c
JOIN orders o ON o.customer_id = c.id
JOIN order_item oi ON oi.order_id = o.id
JOIN product p ON p.id = oi.product_id
WHERE o.status <> 'cancelled'
GROUP BY c.id;
```

Исправьте запрос.

Таблицы: `customer(id, name, country, joined)`, `product(id, title, category, price)`, `orders(id, customer_id, ordered_at, status)` и `order_item(order_id, product_id, qty)`. Даты — текст `YYYY-MM-DD`. Напишите один запрос `SELECT` (допускается `WITH`).
