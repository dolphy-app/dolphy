# ORDER BY и LIMIT

Без `ORDER BY` порядок строк не гарантирован. В упражнениях этого урока порядок строк проверяется.

- `ORDER BY a DESC, b` — сначала по `a` по убыванию, при равенстве по `b`. Добавляйте в конец уникальный или «разрешающий ничью» ключ.
- В SQLite `NULL` считается **меньше** любого значения: при `ASC` он первый, при `DESC` последний. Явно: `NULLS FIRST` / `NULLS LAST` или ключ `x IS NULL`.
- `LIMIT n OFFSET k` берёт `n` строк после пропуска `k`; страница `p` размера `n` — `OFFSET (p - 1) * n`.
- В `ORDER BY` можно использовать алиас столбца и выражение.
