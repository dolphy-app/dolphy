# LEFT JOIN и самосоединение

`LEFT JOIN` сохраняет **все** строки левой таблицы; если пары в правой нет, её столбцы заполняются `NULL`.

- **Анти-соединение** — «найти строки без пары»: `LEFT JOIN ... WHERE right.id IS NULL`.
- Условие на правую таблицу в `WHERE` отбрасывает строки с `NULL` и превращает `LEFT JOIN` в обычный `JOIN`. Условие, которое должно участвовать в сопоставлении, пишут в `ON`.
- **Самосоединение** — таблица соединяется сама с собой под двумя псевдонимами: `emp e LEFT JOIN emp m ON m.id = e.mgr_id` («сотрудник — его руководитель»). Нужен `LEFT JOIN`, иначе пропадёт корень дерева (без руководителя).
- Пары внутри одной таблицы: условие `a.id < b.id` оставляет каждую неупорядоченную пару один раз и убирает пары «сам с собой».
