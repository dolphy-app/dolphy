# SELECT и выражения

`SELECT` выбирает столбцы и вычисляет выражения для каждой строки таблицы из `FROM`.

```sql
SELECT name, salary * 12 AS yearly FROM emp;
```

- Выражение получает имя через `AS`; именно это имя проверяющий сверяет с эталоном (регистр не важен).
- Конкатенация строк — `||`; `+` складывает только числа.
- Деление двух целых в SQLite целочисленное: `7 / 2` = 3. Чтобы получить дробь, одно из чисел делают вещественным: `7 * 1.0 / 2`.
- Любая арифметика с `NULL` даёт `NULL`.
- `DISTINCT` убирает повторяющиеся строки результата целиком.
