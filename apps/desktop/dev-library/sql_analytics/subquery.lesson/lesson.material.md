# Подзапросы: скалярные и IN

Подзапрос — `SELECT` в скобках внутри другого запроса.

- **Скалярный** подзапрос возвращает одно значение (одну строку и один столбец) и подставляется как число: `WHERE salary > (SELECT avg(salary) FROM emp)`. Если он вернёт несколько строк, SQLite молча возьмёт первую — проверяйте.
- **`IN (подзапрос)`** — значение входит в набор, который вернул подзапрос.
- **`NOT IN` и `NULL`:** если в наборе есть хотя бы один `NULL`, `x NOT IN (...)` никогда не бывает истинным. В подзапросе для `NOT IN` добавляйте `WHERE col IS NOT NULL`.
- «Самый-самый» через `ORDER BY ... LIMIT 1` теряет ничьи и зависит от `NULL`; надёжнее `col = (SELECT max(col) FROM ...)`.
- Подзапрос в `FROM` (производная таблица) — временная таблица для внешнего запроса.
