# UNION, INTERSECT, EXCEPT

Операции над множествами склеивают результаты нескольких `SELECT` с одинаковым числом столбцов. Имена столбцов берутся из **первого** запроса.

- `UNION ALL` просто дописывает строки. `UNION` дополнительно убирает дубликаты — в том числе те, которые нужны (число упоминаний, итоговая сумма).
- `INTERSECT` — строки, есть в обоих результатах; `EXCEPT` — есть в первом, но нет во втором.
- Для `INTERSECT` и `EXCEPT` два `NULL` считаются равными, поэтому `EXCEPT` — удобная замена `NOT IN`, которая не ломается из-за `NULL` в списке.
- Итоговую строку отчёта добавляют `UNION ALL` с отдельным агрегатным запросом и меткой: `SELECT 'ALL', count(*) FROM orders`.
- `ORDER BY` пишется один раз, в конце, и относится ко всему объединению.
