# Оконные функции: ранги и PARTITION BY

Оконная функция считает значение по «окну» связанных строк, **не схлопывая** их в одну, как `GROUP BY`.

```sql
SELECT name, salary,
       rank() OVER (PARTITION BY dept_id ORDER BY salary DESC) AS r,
       avg(salary) OVER (PARTITION BY dept_id) AS dept_avg
FROM emp;
```

- `PARTITION BY` делит строки на независимые окна (как ключ группировки), `ORDER BY` внутри `OVER` задаёт порядок в окне.
- При равных значениях: `row_number()` нумерует строки подряд (ничьи получают разные номера), `rank()` даёт одинаковое место и **пропускает** следующие (1, 2, 2, 4), `dense_rank()` — одинаковое место без пропусков (1, 2, 2, 3).
- Любой агрегат (`sum`, `avg`, `count`) с `OVER (...)` превращается в оконный и остаётся рядом со строкой.
- Оконные функции вычисляются после `WHERE`/`GROUP BY`, поэтому **фильтровать по ним в том же `SELECT` нельзя** — оберните запрос в CTE или подзапрос.
- «Первые N в группе»: `row_number()` в CTE, затем `WHERE rn <= N`.
