Верните `dept_id`, `name` и `salary` двух самых высокооплачиваемых сотрудников каждого отдела. Сотрудники без отдела и с неизвестной зарплатой не нужны. При равной зарплате выше тот, чьё имя раньше по алфавиту; ровно два сотрудника на отдел.

Таблицы: `dept(id, name, city)` и `emp(id, name, dept_id, title, salary, bonus, mgr_id, hired, email)`. Даты — текст `YYYY-MM-DD`. Напишите один запрос `SELECT` (допускается `WITH`).
