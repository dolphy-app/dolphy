**Find the bug.** The query should return the names (`name`) of customers who have at least one paid order, each name once. Right now names are repeated:

```sql
SELECT c.name
FROM customer c
JOIN orders o ON o.customer_id = c.id
WHERE o.status = 'paid';
```

Fix the query.
