**Find the bug.** For each customer, the query should return the number of their non-cancelled orders, `orders_n`, and their `revenue`. The order count comes out too high:

```sql
SELECT c.name, count(o.id) AS orders_n, sum(oi.qty * p.price) AS revenue
FROM customer c
JOIN orders o ON o.customer_id = c.id
JOIN order_item oi ON oi.order_id = o.id
JOIN product p ON p.id = oi.product_id
WHERE o.status <> 'cancelled'
GROUP BY c.id;
```

Fix the query.

Tables: `customer(id, name, country, joined)`, `product(id, title, category, price)`, `orders(id, customer_id, ordered_at, status)`, and `order_item(order_id, product_id, qty)`. Dates are `YYYY-MM-DD` text. Write a single `SELECT` query (`WITH` is allowed).
