**Find the bug.** For each employee, the query should return `name` and the bonus as a percentage of salary, `pct`, rounded to one decimal place (for example, `5.6`). Instead it returns whole numbers:

```sql
SELECT name, bonus * 100 / salary AS pct FROM emp;
```

Fix the query. Where the bonus or salary is unknown, `pct` stays `NULL`.

Tables: `dept(id, name, city)` and `emp(id, name, dept_id, title, salary, bonus, mgr_id, hired, email)`. Dates are stored as `YYYY-MM-DD` text. Write a single `SELECT` query (`WITH` is allowed).
