# Команды и панели расширений

Живой документ, пока `status` — `draft` или `active`: `Progress`, `Surprises & Discoveries`, `Decision Log` обновляются вместе с кодом. По завершении фичи переносится в `specs/archive/` и не меняется. Правила — скилл `spec-workflow`.

## Цель

Расширение добавляет в приложение действия и собственные экраны: команды в палитре команд (Ctrl/⌘+K) и панели с пунктом в боковом меню. Команда выполняется кодом расширения, панель рисуется в изолированной рамке и вызывает команды своего расширения. Вместе с хранилищем, настройками и событиями (спека `extension-state`) это позволяет написать расширение «серия дней» целиком без правки ядра.

## Не цели

- Привязка горячих клавиш расширений: `keybinding` — подсказка в палитре, приложение клавиши не назначает.
- Контекстные условия `when`: ключ зарезервирован (манифест с ним отклоняется), добавится позже без поломки.
- Нативное меню Electron и глобальные сочетания ОС.
- Панели в окне приложения для доверенных расширений: панель всегда в рамке (ADR 0008).
- Доступ панели к данным движка и к чужим расширениям: панель вызывает только команды своего расширения.
- Вывод произвольной разметки результатом команды: богатый вывод — это панель.
- Новые разрешения: команды и панели не требуют `permissions`.

## Требования

Наблюдаемое поведение. Проверки — юнит-тесты пакетов, `docs-contributions.test.ts`, e2e `apps/desktop/e2e`.

- R1. Манифест: `contributes.commands` — `{ id, title, description?, category?, keybinding?, palette? }` (`palette: false` скрывает команду из палитры, оставляя её доступной панели; по умолчанию `true`); `contributes.panels` — `{ id, title, module? }` (`module` по умолчанию `./panel.mjs`, `.js` или `.mjs` внутри каталога). `id` — в пространстве расширения (как у тем). `title` 1–60 символов, `category` до 40, `description` до 200, `keybinding` — строка вида `Mod+Shift+L`. Не более 64 команд и 8 панелей на расширение. `id` команд и панелей глобально уникальны. Команды требуют код (`main`), панели — нет (`module` обязателен как файл). Манифест с ключом `when` отклоняется.
- R2. Код: `ctx.commands.register(id, handler)` (в SDK — ключ `commands` в `defineExtension`); команда должна быть объявлена в манифесте, повторная регистрация бросает. Работает в процессе хоста и в ограниченном процессе. Обработчик получает JSON-аргументы и возвращает `undefined`, `{ notify: string }`, `{ openPanel: panelId, props? }` или любой JSON; SDK даёт помощники `notify(text)` и `openPanel(id, props?)`.
- R3. Вызов: `engine.extensions.invokeCommand(extensionId, commandId, args?)` возвращает `{ kind: 'none' | 'notify' | 'openPanel' | 'data', … }`. Движок отклоняет вызов неизвестного, отключённого или необъявленного. Аргументы — JSON до 200 000 символов, результат — до 64 КиБ, `notify.text` до 500 символов, `openPanel` только на объявленную панель того же расширения. Вызов не занимает очередь команд движка. Таймаут и сбой обработчика возвращают типизированную ошибку и НЕ перезапускают хост расширений. Первый вызов лениво активирует расширение; список команд активации не требует.
- R4. Палитра: Ctrl/⌘+K открывает её на любой странице, включая учебную сессию; кнопка в боковом меню открывает её же. Поиск без учёта регистра по названию, категории и id расширения; Enter выполняет, Escape закрывает и возвращает фокус на прежний элемент. Результат `notify` показывается уведомлением приложения (`role="status"`), `openPanel` открывает панель, ошибка команды — понятным сообщением, текст расширения выводится как текст. Команды отключённого, удалённого и ещё не загруженного расширения в палитре не показываются; список обновляется по `contributions-changed` без перезагрузки, выбранная строка не прыгает, команда, пропавшая между выбором и выполнением, даёт сообщение «расширение изменилось».
- R5. Панель: пункт бокового меню с названием расширения (данные) ведёт на `/ext/<extensionId>/<panelId>`. Страница показывает заголовок, кнопку «Назад» и рамку `iframe sandbox="allow-scripts"` (непрозрачный origin, CSP рамки как у элемента ввода) на всю доступную высоту. Модуль панели — `export default { mount(container, ctx) }`, `ctx = { panelId, props, signal, call(commandId, args), onProps(fn) }`. `call` вызывает только объявленные команды собственного расширения (включая `palette: false`), не чаще 20 вызовов в секунду и не более 4 одновременных; результаты `notify` и `openPanel` приложение исполняет само. Панель пропавшего или отключённого расширения показывает пустое состояние со ссылкой на план дня и возвращается к жизни, когда расширение вернётся. Панель доверенного и поставляемого расширения тоже в рамке.
- R6. Живое применение: обновление расширения пересоздаёт его рамки (новая `revision` — новый ключ), открытая панель переживает перезагрузку набора расширений без перезагрузки окна; в режиме разработчика правка модуля панели пересоздаёт рамку.
- R7. Ctrl/⌘+K работает и при фокусе внутри рамки панели: рантайм рамки пересылает приложению только это сочетание (других клавиш и событий родителю не передаётся).
- R8. Доступность и строки: все строки приложения (палитра, пустые состояния, ошибки, «Назад», заголовок рамки) — через `vue-i18n` (`ru`, `en`, числительные формами); названия, категории, тексты уведомлений расширения — данные, без перевода и без HTML. Палитра — диалог с комбобоксом и списком (`role="combobox"`/`listbox`/`option`, `aria-activedescendant`), фокус в рамку панели не перехватывается молча (заголовок страницы получает фокус при входе).
- R9. SDK и инструменты: `defineExtension({ commands })`, `notify`, `openPanel`; `@dolphy-app/extension-sdk/testing` — `loadCommands(module, options)` с `run(id, args)` и теми же правилами, что у хоста; `defineExtensionPanel` для модуля панели. `dolphy-ext build` собирает модуль панели для браузера, `validate` проверяет новые точки. Примеры в `docs/design/extensions.md` проверяются `docs-contributions.test.ts`.
- R10. Каталог: сводка `contributes` принимает необязательные `commands` и `panels`; соответствие манифеста записи индекса проверяется установщиком; карточки и диалог установки показывают «Команды» и «Панели». Индекс с новыми ключами отвергается приложениями старше этой версии (как при `settings`/`events`); терпимый разбор индекса остаётся отдельной задачей.

## Решения

- **Один путь вызова.** Панель и палитра вызывают один RPC `extensions.invokeCommand`; отдельного `callPanel` нет. Привязку «рамка → расширение» делает приложение при создании рамки; идентификатор расширения никогда не читается из сообщения рамки.
- **Вне очереди движка.** `extensions.invokeCommand` в `UNQUEUED` (как `practice.submitAnswer`): медленная команда не замораживает движок. Бюджеты согласованы по цепочке: обработчик 10 с, раннер ограниченного процесса 12 с, клиент движка 14 с; бюджет `fly` для дренажа при замене набора равен бюджету обработчика плюс запас.
- **Таймаут без перезапуска хоста.** `channel.call` с `restart: false`, как у событий: пользовательский клик не должен убивать хост вместе с чужими `grade`. Известный предел (как у событий): синхронный бесконечный цикл в доверенном обработчике внутри процесса хоста вешает хост до его собственного сбоя; ограниченный процесс убивается раннером. Записано в «Пределы».
- **Панели всегда в рамке.** Доверенное расширение получает исполнение кода без ограничений, но не получает окно приложения для панели: иначе панель получила бы `window.dolphy` и вызовы любых расширений. Решение фиксируется ADR 0008.
- **Результат команды — минимальный набор эффектов** (`notify`, `openPanel`), остальное — данные. Приложение исполняет эффекты одинаково для палитры и панели.
- **Палитра в `App.vue`**, чтобы работать на `/session` и `/placement` вне `ShellLayout`; один статический маршрут `/ext/:extensionId/:panelId`, список панелей берётся из реактивного хранилища вкладов (удаление — обычное пустое состояние).
- **Сочетание из рамки.** Рамка не передаёт родителю события клавиатуры; рантайм рамки пересылает только `Mod+K` сообщением `shortcut`, которое приложение принимает после той же проверки источника, что и остальные.
- **Контракт `engine-contract` → 11:** DTO `CommandContributionDto`, `PanelContributionDto`, `CommandResultDto`, `ExtensionContributesDto.commands/panels`, метод `extensions.invokeCommand`, код ошибки `EXTENSION_COMMAND_FAILED` с `details.reason`.
- **Размер рамки панели:** режим `panel` с флагом заполнения: приложение задаёт рамке высоту контейнера, рантайм не сообщает `size`.

## Surprises & Discoveries

Разведка до начала работ: в окне нет ни палитры, ни глобальных сочетаний, ни меню Electron; события клавиатуры внутри рамки до родителя не доходят; `isResolvedExtension` в `protocol.ts` отвергает весь набор, если не учтены новые ключи точек; бюджеты `fly`, раннера и клиента заданы в трёх местах и должны меняться согласованно.
